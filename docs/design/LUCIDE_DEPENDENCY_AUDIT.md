# Lucide Flutter dependency audit

> **Task 006 update, 2026-11-22:** The owner approved integration of exactly `lucide_icons_flutter` **4.0.3**, conditional on technical and license checks. It is now pinned in `pubspec.yaml` and `pubspec.lock` (pub.dev archive SHA-256 `d2ad72b8059ee0ad578d0aeb72bf4e7841c0126f360a8aa37f06e305e1fc7e4b`). The resolved package declares only Flutter as a runtime dependency, Dart `^3.0.0`, and Android/iOS support. Its `LucideIcons.home`, `arrowLeft`, and `arrowRight` are used only by `lib/shared/icons/app_icon.dart`; feature modules do not import it. The package supplies its own openly licensed **icon font** as a Flutter package asset. This is distinct from the unbundled Thmanyah interface fonts. The original Task 005 pending state below is historical.

**License notice record:** The installed package's `LICENSE` contains MIT, copyright © 2024 vqhapp; the permission and copyright notice must accompany copies or substantial portions ([package license](https://pub.dev/packages/lucide_icons_flutter/license), accessed 2026-11-22). [Upstream Lucide](https://lucide.dev/license) lists ISC, copyright © 2026 Lucide Icons and Contributors, and Feather-derived icons under MIT, copyright © 2013-present Cole Bemis (accessed 2026-11-22). `arrowLeft` and `arrowRight` are in the upstream Feather-derived list. Flutter's generated `NOTICES.Z` includes the package MIT notice but did not include the two upstream notices in a locally inspected release APK. Therefore [LUCIDE_NOTICES.txt](../../assets/licenses/LUCIDE_NOTICES.txt) is declared as a bundled application asset containing all three full notices. The eventual app licenses/About experience must expose it to users; no new screen was authorized here. Recheck the bundled file in release artifacts. A documentation link alone does not replace required distributed notices.

**Technical check:** Version 4.0.3's installed `lib/lucide_icons.dart` exposes the three mapped regular-weight `IconData` values and a separate directional variant API. The shared adapter explicitly selects left/right for the back action from ambient `Directionality`; this makes the intended direction testable. No runtime permissions, networking API, native plugin, or new transitive package was introduced by the resolved dependency. Its `pubspec.yaml` declares seven icon-font assets. All seven remained in the local release APK despite only regular-weight icons being referenced: their total compressed entry size was approximately 1.9 MiB. The package's font assets were **not** tree-shaken by the local release build (Flutter did report tree shaking for Material/Cupertino fonts). The release APK measured 43.2 MB; this is a local build observation, not a controlled before/after size comparison. The release manifest had no `INTERNET` permission. The debug manifest's `INTERNET` permission comes from the pre-existing Flutter debug manifest, and no Android/iOS source configuration changed.

**Checked:** 2026-11-22. **Decision:** Lucide is the owner's preferred icon direction; package installation remains **pending owner approval**. No icon package or binary was added in Task 005.
