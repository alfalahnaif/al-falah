# ADR-0003: Religious content source governance

- Status: Proposed
- Decision owner: Product owner
- Date: 2026-11-16

## Decision
No religious content is imported, generated, or distributed until the exact source, edition/version, license/permission, attribution, validation plan, and required human review have been documented and approved.

## Special rule for Quran text
Canonical Quran text must remain verbatim. No normalization, diacritic stripping, punctuation cleanup, substitutions, or automatic correction. Search normalization, if needed, is a separate derived index and is never displayed as canonical text.

## Consequences
Content selection may slow feature development, but prevents unverified text, attribution, and redistribution risks.
